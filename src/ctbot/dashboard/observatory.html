          Strategy library

          Every strategy Autopilot can use, one per row: whether it's trading or benched and why, how it would have done over the past year (a simulation), and how its real practice trades have gone. Click a row to see how it works, with charts. Simulated results don't promise future returns.

          Growth of $5,000 since 2010

          What $5,000 would have grown to with each idea, using real past prices. Higher is better; a smoother line means fewer scary drops. Pick which lines to show in the leaderboard below. "Log" draws a 10% move the same size whether the account is small or large.

          Crash test 1999-2026, including the dot-com crash

          How each idea would have survived the 2000-02 crash (Nasdaq fell about 80%), 2008 and 2020. 2x and 3x funds didn't exist back then, so they're rebuilt from the Nasdaq-100's daily moves. A red worst drop (60%+) means it nearly wiped out.

          No-hindsight test each year picked using only the past

          A fairer test: each year, the setting (how many days of average price to look at) is picked using only the 5 years before it, as if you were living through it. If these numbers stay close to the leaderboard's, the result wasn't just hindsight.

          Backtest leaderboard

          Every idea tested on 16 years of real prices, after trading costs, best first. Each was designed using 2010-19, then judged on 2020-26, years it never saw. Click a row for the full explanation and a chart; tick the box to add it to the growth chart.
